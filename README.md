Welcome to the source repository for my personal portfolio website, engineered to showcase data engineering pipelines, end-to-end ETL architectures, and cloud data workflows.

---

## 🌟 Features

- **Dynamic Theme Switcher:** Fully responsive Light and Dark modes with smooth color transitions and persistent state via `localStorage`.
- **Curated Color Palette:** Slate Navy (`#2f486d`), Warm Linen Cream (`#f3eae0`), Deep Midnight Slate (`#223148`), and Fresh Sage Green (`#d2e7b8`).
- **Interactive Project Showcase:** Live GitHub integration linking directly to open-source data engineering projects:
  1. `Azure-Data-Factory-Sales-Pipeline`
  2. `Telecom-ETL-SSIS-Project`
  3. `Real-Time-E-Commerce`
  4. `wuzzuf-airflow-pipeline`
- **Freelance & Full-Time Availability:** Dedicated inquiry channels and contact integration for freelance client projects and pipeline contracts.
- **Responsive & Accessible Design:** Optimized across mobile, tablet, and desktop viewports with zero layout shifts.
